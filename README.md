# FoodCart POS

A simple digital POS and order-management app for small food carts, street-food stalls, and independent food sellers.

## Current features

- Custom food-cart name
- Menu management
- Fast tap-based ordering
- Customer name
- Cash / UPI selection
- Automatic totals
- Order completion
- Today's sales dashboard
- Order history
- UPI QR generation
- Local browser storage
- Mobile-friendly layout
